Connect your NAS

NAS Player talks directly to Audio Station on your Synology NAS. The connection is always encrypted (https) and needs a valid certificate. Without a NAS, try the app in demo mode.

What you need

  • A Synology NAS with Audio Station installed and running, with your music indexed
  • A user who may use Audio Station (DSM: Control Panel → Application Privileges)
  • An address that reaches your NAS: https with a valid certificate (for example through DDNS) or QuickConnect

At home: find it automatically

Open Settings (gear icon) in the app and tap “Search for NAS on the network”. Your iPhone must be on the same Wi-Fi, without VPN. The app fills in the address; you add user name and password.

On the road: an address with a certificate

Enter the address in Settings, for example https://your-nas.example.com:5001. 5001 is the default https port of DSM. This is how you get such an address:

  1. Set up a DDNS name: Control Panel → External Access → DDNS (Synology offers free names, for example under synology.me).
  2. Create a certificate: Control Panel → Security → Certificate → Add, then request a Let’s Encrypt certificate for that name.
  3. Forward port 5001 to the NAS on your router (or use a reverse proxy).
  4. Enter the address in the app and add user name and password.

Names in DSM can differ depending on version and language. Before you make the NAS reachable from the internet, check for strong passwords and automatic blocking (Control Panel → Security → Protection).

Alternative: QuickConnect

Instead of the DDNS address, you can enter your QuickConnect address in Settings. You find it in DSM under Control Panel → External Access → QuickConnect. Add user name and password as usual.

Two-factor authentication

Users with two-factor authentication turned on cannot sign in with the current version yet. Until then, create a separate user for the app that may only use Audio Station and the music folder.

Error messages and fixes

  • The NAS cannot be reached: check address, port, and network; check port forwarding on the router and the firewall in DSM.
  • Certificate not valid: the app only accepts valid certificates, not self-signed ones. The name in the certificate must match the address.
  • Only https allowed: the address must start with https://.
  • No Synology NAS answers here: address or port is wrong, for example another device answers instead of the NAS.
  • User name or password is wrong: check what you typed; the user must not be disabled.
  • No permission for Audio Station: Control Panel → Application Privileges.
  • The NAS has blocked this access: automatic blocking has blocked the address (Control Panel → Security → Protection); unblock it.
  • Audio Station not available: install and start the package in Package Center.
