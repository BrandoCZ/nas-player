Connecter votre NAS

NAS Player dialogue directement avec Audio Station sur votre NAS Synology. La connexion est toujours chiffrée (https) et exige un certificat valide. Sans NAS, essayez l'app en mode démo.

Ce qu'il vous faut

  • Un NAS Synology avec Audio Station installée et démarrée, musique indexée
  • Un utilisateur autorisé à utiliser Audio Station (DSM : Control Panel → Application Privileges)
  • Une adresse https avec un certificat valide

À la maison : détection automatique

Dans l'app, ouvrez Réglages (icône d'engrenage) et touchez « Rechercher le NAS sur le réseau ». L'iPhone doit être sur le même Wi-Fi, sans VPN. L'app renseigne l'adresse ; vous ajoutez utilisateur et mot de passe.

En déplacement : une adresse avec certificat

Saisissez l'adresse dans les Réglages, par exemple https://votre-nas.exemple.fr:5001. 5001 est le port https par défaut de DSM. Voici comment obtenir une telle adresse :

  1. Configurez un nom DDNS : Control Panel → External Access → DDNS (Synology propose des noms gratuits, par exemple sous synology.me).
  2. Créez un certificat : Control Panel → Security → Certificate → Add, puis demandez un certificat Let’s Encrypt pour ce nom.
  3. Sur le routeur, redirigez le port 5001 vers le NAS (ou utilisez un proxy inverse).
  4. Saisissez l'adresse dans l'app et ajoutez utilisateur et mot de passe.

Les intitulés de DSM peuvent varier selon la version et la langue. Avant de rendre le NAS accessible depuis Internet, vérifiez des mots de passe solides et le blocage automatique (Control Panel → Security → Protection).

Authentification à deux facteurs

Les utilisateurs dont l'authentification à deux facteurs est activée ne peuvent pas encore se connecter avec la version actuelle. D'ici là, créez pour l'app un utilisateur dédié, autorisé uniquement pour Audio Station et le dossier de musique.

Messages d'erreur et solutions

  • Le NAS est injoignable : vérifiez adresse, port et réseau ; contrôlez la redirection de port du routeur et le pare-feu dans DSM.
  • Certificat non valide : l'app n'accepte que des certificats valides, pas auto-signés. Le nom du certificat doit correspondre à l'adresse.
  • Seul https est autorisé : l'adresse doit commencer par https://.
  • Aucun NAS Synology ne répond ici : adresse ou port incorrects, par exemple un autre appareil répond à la place du NAS.
  • Nom d'utilisateur ou mot de passe incorrect : vérifiez la saisie ; l'utilisateur ne doit pas être désactivé.
  • Autorisation manquante pour Audio Station : Control Panel → Application Privileges.
  • Le NAS a bloqué cet accès : le blocage automatique a bloqué l'adresse (Control Panel → Security → Protection) ; débloquez-la.
  • Audio Station indisponible : installez et démarrez le paquet dans Package Center.
